# 🛠️ Worker App

A simple application to **find and hire skilled workers**.  
Built with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), and modern tooling.  

---

## 🚀 Features

- 🔍 Browse and filter workers by services and price range  
- 📱 Responsive UI with modern design (Tailwind + Shimmer UI loading states)  
- ⚡ Fast navigation with Next.js App Router  
- 🎨 Skeleton loading screens for better UX  
- 🛡️ SEO-friendly metadata and icons  
- 🔑 Ready to integrate authentication and APIs
